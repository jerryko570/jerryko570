# Hi, I'm Jerry 👋

14년 차 프로덕트 디자이너였지만, 현재는 디자인과 프론트엔드의 경계에서 개발 코드로 디자인을 구현하는 디자인 엔지니어 이나래입니다.

저는 디자인과 개발이 서로 다른 영역처럼 보이지만, 결국 같은 방향을 향한다고 생각합니다.
누가 이 서비스를 사용하는지, 왜 만들어야 하는지에 대한 고민 끝에는 언제나 사람이 있고, 
디자인과 기술은 이를 해결하기 위한 감성적이면서도 논리적인 도구라고 생각합니다.

저는 이 접점에서 디자인을 엔지니어링하는 과정에 큰 동기와 성장을 느끼고 있습니다.
디자인과 구현 사이를 자연스럽게 연결하며, 작업 과정의 협업 비용을 줄이고 더 빠르게 가치를 전달하는 역할을 지향합니다.

최근에는 디자인 · 프론트엔드 · 백엔드(스키마·아키텍처) · AI 네 가지 영역을 함께 평행으로 학습하고 있으며,
디자인 시스템 구축부터 컴포넌트 설계까지 유지보수성과 확장성을 고려한 UI 파이프라인을 만드는 데 집중하고 있습니다.

최종적으로는 데이터 흐름과 구조를 깊이 이해하고, 아키텍처부터 아름다운 사용자 경험까지 설계할 수 있는 사람이 되는 것이 목표입니다.

## 🌱 Writing & Learning System

혼자 공부한 내용을 기록하고 축적하기 위해 **성장 블로그**를 운영하고 있습니다.
디자인, 프론트엔드, AI까지 현재 학습 중인 분야를 꾸준히 정리하며, 단순한 기록이 아니라 **지식을 재사용 가능한 형태로 구조화하는 것**을 목표로 합니다.

공부 시간을 효율적으로 쓰기 위해 최신 기술 아티클을 직접 찾아 읽는 과정을 자동화했습니다.
공식 블로그의 RSS를 수집하고, 이를 학습 노트 형태로 재구성해 블로그까지 이어지는 **콘텐츠 자동화 파이프라인**을 구축했습니다.

- 🔗 블로그: https://jerryko570.github.io/
- 🔗 자동화 구조 정리: 블로그 자동화 세팅 케이스 스터디
https://jerryko570.github.io/posts/blog-automation-setup-note/

### Automation Pipeline

* Python 스크립트로 Figma · React · Vercel · Anthropic 공식 블로그 RSS 수집
* GitHub Actions + Claude Code 기반으로 하루 한 편의 학습 노트 자동 생성
* Figma 시안을 기반으로 썸네일 자동 생성
* 블로그 배포까지 연결되는 개인 학습 자동화 환경 구축

단순히 정보를 모으는 것을 넘어,
**배우는 과정 자체를 시스템으로 만들고 지속 가능하게 운영하는 것**에 관심이 있습니다.
